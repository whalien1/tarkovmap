# Phase 8 简单 GUI 实施报告

日期：2026-08-25

## 结果

新增 `Tools/MapPackBuilder.Gui` WinForms 项目。它面向不希望记忆命令的项目维护者，覆盖：

- 自动识别正式 `Data` 和当前版本。
- 根据正式版本及已有工作结果建议下一个未使用版本号。
- 获取 PvE 来源数据。
- 在独立目录构建整批 MapData。
- 查看 Validation + Diff 报告并重新校验。
- 明确确认代表地图和超过 30% 的数量变化，自动生成精确审批文件。
- 导出正式 ZIP。
- 应用到正式程序和恢复上一个可用版本。
- 打开构建报告和工作目录。

GUI 不提供地图、点位或审批 JSON 编辑器。

## 安全设计

- 构建期间禁用全部操作按钮，避免并发修改。
- 测试包或快照目录已存在时拒绝覆盖，要求改用新版本号或新工作目录。
- 人工审批不能绕过内容哈希、文件缺失等结构性 Error。
- 导出 ZIP 前必须存在人工验收文件；正式应用前必须存在由 CLI 校验生成的 ZIP。
- 应用与恢复都显示后果确认，并继续调用现有原子备份/恢复实现。
- GUI 通过隐藏的独立 `MapPackBuilder.exe` 子进程执行命令并实时收集日志，避免 WinForms 高 DPI 进程改变 SVG/GDI+ 栅格化结果。
