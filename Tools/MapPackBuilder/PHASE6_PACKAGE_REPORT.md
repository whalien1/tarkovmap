## 已实现

- `pve-package`：重新验证测试包和人工验收，确定性生成 ZIP，随后解包复验。
- ZIP 包含运行时 Data、API/SVG/许可证/校准快照、Validation 报告和审批记录。
- `pve-apply`：校验正式包，验证当前与新 Data，保留唯一备份后在同一磁盘原子切换目录。
- `pve-restore`：验证备份、恢复旧 Data，并清空备份槽。
- 路径安全限制：正式目标必须明确命名为 `Data`，备份必须是其同级独立目录。
- 异常回滚：目录切换或切换后冒烟检查失败时自动恢复原 Data。
